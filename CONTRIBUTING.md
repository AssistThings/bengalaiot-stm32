# Como contribuir

**Português** · [Español](CONTRIBUTING.es.md) · [English](CONTRIBUTING.en.md)

Obrigado por ajudar! Este projeto apoia pessoas com deficiência visual.

## O que muda onde

- Pinos, drivers e conexão desta placa: aqui.
- Algoritmo, ajustes, protocolo: no [bengalaiot-core](https://github.com/AssistThings/bengalaiot-core).

## Antes de abrir o pull request

- [ ] Compila sem erros.
- [ ] A conformidade termina com `failed=0`.
- [ ] A lista de testes com hardware foi feita, e o pull request diz em qual placa.
- [ ] Textos novos existem em português, espanhol e inglês.

Usamos [Conventional Commits](https://www.conventionalcommits.org/pt-br/), por exemplo `fix(hal): corrigir tempo de eco`.

Escreva "pessoa com deficiência visual".
