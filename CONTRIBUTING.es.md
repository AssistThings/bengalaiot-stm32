# Cómo contribuir

[Português](CONTRIBUTING.md) · **Español** · [English](CONTRIBUTING.en.md)

¡Gracias por ayudar! Este proyecto apoya a personas con discapacidad visual.

## Qué cambia dónde

- Pines, controladores y conexión de esta placa: aquí.
- Algoritmo, ajustes, protocolo: en [bengalaiot-core](https://github.com/AssistThings/bengalaiot-core).

## Antes de abrir el pull request

- [ ] Compila sin errores.
- [ ] La conformidad termina con `failed=0`.
- [ ] Se hizo la lista de pruebas con hardware, y el pull request dice en qué placa.
- [ ] Los textos nuevos existen en portugués, español e inglés.

Usamos [Conventional Commits](https://www.conventionalcommits.org/es/), por ejemplo `fix(hal): corregir tiempo de eco`.

Escribe "persona con discapacidad visual".
