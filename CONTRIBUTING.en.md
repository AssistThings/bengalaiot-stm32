# Contributing

[Português](CONTRIBUTING.md) · [Español](CONTRIBUTING.es.md) · **English**

Thank you for helping! This project supports people with visual impairments.

## What changes where

- This board pins, drivers and connection: here.
- Algorithm, settings, protocol: in [bengalaiot-core](https://github.com/AssistThings/bengalaiot-core).

## Before opening the pull request

- [ ] It builds with no errors.
- [ ] Conformance ends with `failed=0`.
- [ ] The hardware test list was done, and the pull request says on which board.
- [ ] New texts exist in Portuguese, Spanish and English.

We use [Conventional Commits](https://www.conventionalcommits.org/en/), for example `fix(hal): correct echo timing`.

Write "person with a visual impairment".
